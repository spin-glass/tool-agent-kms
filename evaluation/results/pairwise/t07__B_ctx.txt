以下は、Reactで複数の入力フィールド（name, email, age）を1つのコンポーネントで管理する方法の例です。stateはオブジェクトでまとめられ、入力のたびにimmutableに更新されます。

```jsx
import { useState } from 'react';

export default function FormComponent() {
  // 初期 state をオブジェクトで設定
  const [formData, setFormData] = useState({
    name: '',
    email: '',
    age: ''
  });

  // 各フィールドの入力ハンドラ
  const handleInputChange = (e) => {
    const { name, value } = e.target;
    setFormData({
      ...formData,
      [name]: value
    });
  };

  // フォーム送信ハンドラ
  const handleSubmit = (e) => {
    e.preventDefault();
    // フォームデータを処理
    console.log('Form Data Submitted:', formData);
  };

  return (
    <form onSubmit={handleSubmit}>
      <div>
        <label>
          Name:
          <input
            type="text"
            name="name"
            value={formData.name}
            onChange={handleInputChange}
          />
        </label>
      </div>
      <div>
        <label>
          Email:
          <input
            type="email"
            name="email"
            value={formData.email}
            onChange={handleInputChange}
          />
        </label>
      </div>
      <div>
        <label>
          Age:
          <input
            type="number"
            name="age"
            value={formData.age}
            onChange={handleInputChange}
          />
        </label>
      </div>
      <button type="submit">Submit</button>
    </form>
  );
}
```

### 説明

1. **state 管理**: `useState` フックを使用して、`formData` というオブジェクト型の state を定義。このオブジェクトは、`name`, `email`, `age` の3つのプロパティを持つ。

2. **入力ハンドラ**: `handleInputChange` 関数は、各入力フィールドの変更を監視し、`setFormData` を使用して state を更新。`...formData` は現状の state を保持し、`[name]: value` で特定のフィールドを更新。

3. **フォーム送信**: `handleSubmit` 関数は、フォームの送信を処理。`e.preventDefault()` でデフォルトの送信動作を防ぎ、`console.log` で送信されたデータを表示。

4. **UI レンダリング**: 各入力フィールドは、`value` プロパティで state とバインディングされ、`onChange` ハンドラで入力変更を処理。

このアプローチは、Reactのstate管理の基本的なパターンであり、複数の入力フィールドを効率的に管理するための一般的な方法です。
